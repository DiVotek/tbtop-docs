`tbtop/admin` is a PHP DSL and React client for building admin panels on top
of a Laravel app: pages, fields, tables and actions declared in PHP, rendered
by an Inertia React client.

## Where to start

- [Install](/docs/getting-started/install): add both packages to a Laravel app, then [register a panel](/docs/getting-started/panel), [wire sign-in](/docs/getting-started/authentication) and [write your first page](/docs/getting-started/first-page). [Deploy](/docs/getting-started/deploy) covers production.
- [Authoring](/docs/authoring/pages): the DSL for [pages](/docs/authoring/pages), [fields](/docs/authoring/fields), [forms](/docs/authoring/forms), [tables](/docs/authoring/tables), [actions](/docs/authoring/actions) and [navigation](/docs/authoring/navigation).
- [Extending](/docs/extending/client-components): your own [client components](/docs/extending/client-components), [live regions](/docs/extending/live-regions) and the [wire contract](/docs/extending/contracts) between PHP and the client.
- [API reference](/docs/api/builder): every builder method, generated from the package's source comments.
