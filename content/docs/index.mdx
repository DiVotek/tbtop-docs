`tbtop/admin` is a PHP DSL and React client for building admin panels on top
of a Laravel app: pages, fields, tables and actions declared in PHP, rendered
by an Inertia React client.

## Where to start

- [Getting started](/docs/getting-started/install) — install the package, register a panel and write your first page.
- [Authoring](/docs/authoring/pages) — the DSL for pages, fields, tables, forms, actions and navigation.
- [Extending](/docs/extending/client-components) — client components, live regions and the contracts they implement.
- [API reference](/docs/api/builder) — generated from the package's own source comments: builders, fields, blocks, tables, actions, notifications and the panel.
