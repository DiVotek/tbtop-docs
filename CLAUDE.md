# tbtop-docs

Fumadocs site for `tbtop/admin` (repo `DiVotek/tbtop`, public), describing the
latest patch of its current 0.x line. Hosted on Cloudflare Workers as static
assets — a React Router SPA with `ssr:false`, fully prerendered at build time.

## Pinned tag

`PINNED_TAG` in `app/lib/shared.ts` is the only place the described release
is pinned. To bump it: update `PINNED_TAG`, run `npm run sync:api`, review
the diff in `content/docs/api/`, commit both together.

## Generated content

`content/docs/api/*.mdx` and its `meta.json` are generated by
`scripts/sync-api.ts` (`npm run sync:api`) from `docs/ai/api/*.md` in
`DiVotek/tbtop` at `PINNED_TAG`. Never hand-edit them — edit the script and
rerun it. Everything else under `content/docs/` is hand-written.

## Gates

```bash
npm run lint
npm run format:check
npm run types:check
npm run build
```

No persistent test suite; the build's prerender step is the correctness
check for MDX and routes.

## Deploy

`CLOUDFLARE_ACCOUNT_ID=9fc01736a7873ba44582cf173fc5a157 npx wrangler deploy` — the
account that holds the tbtop.dev zone. `wrangler.jsonc` routes docs.tbtop.dev as a
custom domain: Cloudflare creates its DNS record and certificate on deploy, so
no record for that host may exist in the zone beforehand.

## Tabletop CMS

`tbtop/cms` is a private package; nothing about its internals belongs here.
The CMS docs page stays "coming soon" until its closed beta opens.

## Anonymise production examples

An example drawn from a private production project is rewritten generic
before it lands here: no project names, domains, or client code verbatim.
